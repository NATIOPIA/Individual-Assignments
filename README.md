# Individual-Assignments
* This repository has been created for the purpose of individual assignments in the course "Data Stracture and Algorithm" at Dilla University . The repository will be used to store and manage individual assignments submitted by students. 
* The repository is organized into folders, each representing a specific assignment. Each folder contains the following files : 
             * README.md : This file contains information about the assignment, including the problem statement, submission guidelines, and any other.
             * Finding a number : This file contains the code for the finding a numbers in array assignment.
             * Iterative&Recursive : This file contains the code for the iterative and recursive assignment.
             * Pointer sorting algorithm : This file contains the code for the pointer sorting algorithm assignment.
             * Searching Algorithms : This file contains the code for the Exponential, Jump and Hashing-Based searching algorithms.
             * The repository is managed by the instructor, who will review and provide feedback on the assignments submitted by students.
